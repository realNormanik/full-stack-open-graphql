# Full Stack Open – GraphQL Module

This document provides a summary of my learning experience while completing the **[GraphQL Module](https://fullstackopen.com/en/part8)** of the [Full Stack Open](https://fullstackopen.com/en/) course offered by the University of Helsinki. The module focuses on building modern applications using GraphQL, Apollo Server, Apollo Client, and React. Through hands-on exercises and practical projects, I gained experience in designing GraphQL APIs, managing application data, and integrating frontend applications with GraphQL backends.

## 📚 Course Overview

The GraphQL module covers the following topics:

- **Introduction to GraphQL**: Understanding GraphQL fundamentals, its advantages over REST, and how clients communicate with GraphQL APIs.
- **GraphQL Server**: Building a GraphQL backend using Node.js and Apollo Server.
- **Database Integration**: Connecting a GraphQL server to MongoDB and managing application data using Mongoose.
- **Queries and Mutations**: Defining GraphQL schemas, object types, queries, mutations, and resolvers.
- **Apollo Client**: Integrating GraphQL APIs with React applications using Apollo Client.
- **Managing Application State**: Handling server-side data, caching, and updating the frontend after mutations.
- **User Authentication**: Implementing authentication and authorization in GraphQL applications.
- **Advanced GraphQL Features**: Exploring more advanced GraphQL concepts, including subscriptions and real-time communication.

## 🧠 Skills and Knowledge Acquired

### 🔗 GraphQL Fundamentals

- Understood the differences between GraphQL and traditional REST APIs.
- Learned how GraphQL schemas define the structure and capabilities of an API.
- Worked with GraphQL object types, scalar types, and input types.
- Understood how clients request specific data fields.
- Explored the benefits of strongly typed API definitions.

### 🖥️ Backend Development with Apollo Server

- Built GraphQL APIs using Node.js and Apollo Server.
- Defined GraphQL schemas using GraphQL SDL (Schema Definition Language).
- Implemented queries and mutations to retrieve and modify application data.
- Created resolvers to handle GraphQL operations.
- Organized backend logic and managed relationships between different data types.
- Integrated GraphQL servers with MongoDB using Mongoose.

### 🔄 Queries, Mutations and Data Management

- Implemented queries for retrieving application data.
- Created mutations for adding, updating, and deleting records.
- Used GraphQL arguments to filter and identify specific resources.
- Managed nested objects and relationships between entities.
- Handled validation and errors in GraphQL operations.

### ⚛️ Apollo Client and React Integration

- Integrated Apollo Client with React applications.
- Used the `useQuery` hook to retrieve data from GraphQL APIs.
- Used the `useMutation` hook to perform data modifications.
- Managed loading and error states when communicating with the server.
- Configured Apollo Client and its connection to GraphQL endpoints.
- Used Apollo Client's caching mechanisms to reduce unnecessary network requests.
- Updated cached data after performing mutations.

### 🔐 Authentication and Authorization

- Implemented user authentication in GraphQL applications.
- Used JSON Web Tokens (JWT) for authentication.
- Passed authentication credentials through HTTP request headers.
- Implemented authorization logic in GraphQL resolvers.
- Restricted access to selected queries and mutations based on user authentication.

### 📡 GraphQL Subscriptions

- Explored GraphQL subscriptions for real-time application updates.
- Understood the differences between queries, mutations, and subscriptions.
- Learned how subscriptions enable server-to-client communication.
- Explored how real-time updates can be integrated into frontend applications.

### 🛠️ Projects and Exercises

- Throughout the module, I completed various exercises and practical projects, including:
- Building a GraphQL server using Apollo Server and Node.js.
- Creating a backend API for managing books and authors.
- Implementing GraphQL queries and mutations for CRUD operations.
- Connecting a GraphQL backend to MongoDB using Mongoose.
- Developing a React frontend integrated with Apollo Client.
- Implementing functionality for adding books and authors.
- Managing relationships between books and authors.
- Implementing user authentication and restricting access to protected operations.
- Exploring real-time communication using GraphQL subscriptions.
